# Radio cue assets

`radio-open.wav` and `radio-close.wav` are original project assets used at the
push-to-talk boundaries. They are mono, 16-bit PCM WAV files sampled at 48 kHz.

The open cue is 250 ms and the close cue is 300 ms. Both use only synthesized
radio noise and a small mechanical transient; they contain no third-party samples.
