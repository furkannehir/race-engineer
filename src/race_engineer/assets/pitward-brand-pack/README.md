# Pitward logo pack — papaya v1

Primary logo: `svg/pitward-logo-horizontal.svg`
Stacked logo: `svg/pitward-logo-stacked.svg`
Symbol: `svg/pitward-icon.svg`
Synth avatar: `png/pitward-avatar.png` (1024 × 1024, cream background)
Windows icon: `icons/pitward.ico`
Browser favicon: `icons/favicon.ico`

## Artwork
Faithfully vectorized from the approved papaya radio concept, using smooth closed Bézier paths and flat colours. Presentation labels and background removed. The original custom wordmark is outlined, so no font installation or external font dependency is needed. It is not editable live text. All SVGs contain real vector geometry, with no embedded raster images.

Papaya: #FF8000. Charcoal: #22262A. Cream: #F5F0E6.
Colours are Pitward's working palette inspired by papaya motorsport colours, not an official team specification or affiliation.

## Usage
Use the regular logos on light backgrounds. Use `logo-horizontal-dark` or `icon-dark` on dark backgrounds. Most PNGs and SVGs have transparent backgrounds; the avatar and Apple touch icon intentionally have a cream background. Keep the supplied spacing and proportions. Use the icon when the wordmark would be too small to read.

Use `icon-small.svg` at 16–48 px. This intentionally simplified drawing makes the antenna, eyes and microphone easier to read. Larger Windows icon frames use the full master artwork. The favicon and ICO files contain multiple sizes.

## Recolouring
Edit the named groups in an SVG editor (Inkscape, Illustrator, Figma), or replace the three hex values in the source. Keep the dark/light expression contrast. The monochrome icon has transparent face cutouts and is intended for single-colour applications.
