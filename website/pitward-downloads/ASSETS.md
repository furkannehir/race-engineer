# Racing hero

File: `public/assets/racing-hero.png`.

Generated with the built-in Imagegen tool, then copied into this project. This is
original campaign artwork, not a screenshot of iRacing or a vehicle endorsement.
The logo, favicon, and actual desktop preview are separate existing project assets.

The Anton display font is bundled from the [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/anton)
under the SIL Open Font License. The full license is included at
`public/assets/fonts/OFL.txt`; the page makes no font request to an external service.

> distant trackside floodlights and mist. Matte charcoal, midnight gray, papaya

> physically believable car, crisp purposeful composition, deep shadows with
> readable detail, premium understated atmosphere. Do not generate any interface,
