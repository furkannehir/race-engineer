# Pitward 0.2.0 release preparation

Prepared **18 November 2026**. This is a minor feature release: new lap/race data
and core calculations, plus a source-only Ministral conversation preview. It is
not a desktop model migration. The Windows application retains LFM3-1.7B and
component set 3; the existing speech/runtime distribution reviews still apply.

- Version: `0.2.0`; release tag: `v0.2.0`.
- [Prepared release notes](../../distribution/RELEASE_NOTES.md).
- [Tagged workflow](https://github.com/furkannehir/race-engineer/actions/workflows/release.yml).
- Expected assets: `Pitward-0.2.0-windows-x64.zip`,
  `Pitward-Setup-0.2.0-windows-x64.exe`, and `SHA256SUMS.txt`.

The release workflow creates a **draft** after a successful Windows build and
clearance check. This record does not claim published assets, a completed frozen
build, clean-machine acceptance or a live Ministral test. Keep the website
deployment and public publication separate from pushing source/tag metadata.
The website source targets 0.2.0 and only enables downloads after the matching
public assets exist; the currently deployed site is unchanged by a Git push.

## Scope and validation

The adapter selects 25 SDK variables. Five new typed core calculations cover
last/best timing, their difference, race progress and conservative finish fuel
with a one-lap reserve. The source preview exposes 14 implemented core capabilities,
26 normalized paths and 26 operations. Lap-time radio wording is deterministic;
speed and per-second gap rates are excluded from the preview's read surface.

Source suite: 965 passed, two optional NumPy/audio skips. Ruff, mypy and whitespace
checks passed before release preparation. The version-aligned website's 13 tests
and Worker build also pass. No website deployment was performed during preparation.
The previous expanded English GPU development replay delivered 135/140 replies;
that is not a semantic accuracy
score. Model/topic selection, fastest-driver questions, unsupported projections,
ambiguous targets and reserve wording remain open. No new voice playback or
live/VR acceptance is implied. See the
[conversation test record](../dialogue-model-comparison.md#lap-timing-race-progress-and-fuel-18-november-2026).

Before public publication, inspect the tagged Windows build, frozen workers,
installer identity, archive/installer checksums and the applicable acceptance
checks in [distribution](../distribution.md). Do not change the LFM component
manifest or claim installed Ministral support merely to publish this tag.
