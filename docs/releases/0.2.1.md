# Pitward 0.2.1

This patch connects the checked Ministral 3 3B Q4_K_M implementation to the live
desktop radio and Windows model setup. It corrects the missing desktop migration
in 0.2.0. The existing 0.2.0 tag and downloads remain unchanged.

- Release tag: `v0.2.1`.
- [GitHub release](https://github.com/furkannehir/race-engineer/releases/tag/v0.2.1).
- [Release notes](../../distribution/RELEASE_NOTES.md).
- Component set 4: pinned Ministral weights, existing llama.cpp b12088 CPU,
  Qwen3-ASR and multilingual Chatterbox V2 assets.

Upgrade from 0.1.0, 0.1.1 or 0.2.0 over the existing installation. The new app
offers component setup for missing Ministral weights, reuses existing speech
assets and restarts after setup. Once the owned server successfully loads the
verified replacement, migration records the switch and removes the verified
obsolete LFM model, freeing 1,099,627,808 bytes. Failed starts, locked files,
source caches and custom models retain their existing files.

Validation before tagging: 1000 Python tests passed (two optional NumPy cases
skipped); Ruff and strict mypy passed. Website tests passed (13) and the Worker
build passed. Migration using real GGUF hard links in a temporary cache removed
only the old link and the loaded Ministral server still answered a synthetic
position question. Original source weights remained intact. Native tests cover
delivery refresh, playback-only memory and cancellation; migration tests cover
checksum mismatch, path redirection, custom files, stop and locked-file retry.

Source live testing produced five played replies averaging 0.36 seconds in the
Ministral stage. A prior source smoke synthesized English/Turkish replies through
one Chatterbox worker without playback. Frozen build verification and publication
details are recorded after the release workflow completes.

English is primary. Turkish social understanding remains imperfect. Installed
builds use CPU runtimes; source CUDA timings do not establish installed race
latency. Cold CPU requests can take about 19 seconds before synthesis. A source
Chatterbox startup OSError occurred once and restart succeeded; its cause is
unknown. Clean installer/upgrade interaction and full installed microphone/VR
acceptance are not established by source or offscreen smoke checks.
