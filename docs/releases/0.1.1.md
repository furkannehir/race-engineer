# Pitward 0.1.1 release

Prepared on 2026-11-15 (Europe/Istanbul), at the maintainer's explicit request to
release v0.1.1. The previous public v0.1.0 tag and assets remain unchanged.

## Scope

The patch includes installed Chatterbox startup fixes, automatic restart after
component setup, verified user-approved installer updates, uninstall cache cleanup,
and microphone/PTT diagnostics from `d83dde8`.

The component manifest remains set 3: LFM3-1.7B Q4_K_M, Qwen3-ASR and Chatterbox
Multilingual 0.1.7 built-in V2 voice. There are no model-weight or license changes;
the existing [distribution review](../../distribution/REVIEW-0.1.0.md) still applies.

## Validation and acceptance

- Maintainer reported the installed test app's microphone path working again and
  explicitly requested publication. LFM response quality remains a known limitation.
- Source tests before the version bump: 732 passed, 2 optional NumPy skips;
  Ruff and mypy passed. Final tagged checks run in the Windows package workflow.
- Local frozen default-voice synthesis covered English/Turkish replies and automatic
  announcements through one reused worker without audio playback. Installed logs
  also confirmed ASR and Chatterbox startup.
- The updater's equal/newer/older releases, cancellation, corruption rejection,
  idle-only prompts and lock/installer handoff have automated coverage. Actual
  public-version upgrade, clean-machine uninstall and racing latency are not
  independently established by these tests.

The release workflow builds fresh versioned binaries and a draft release. The
published source identity, checksums, workflow and download verification are
recorded after the final build completes.
