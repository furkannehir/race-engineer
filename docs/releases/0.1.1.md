## Validation and acceptance

- Maintainer reported the installed test app's microphone path working again and
  explicitly requested publication. LFM response quality remains a known limitation.
- Source suite: 732 passed, 2 optional NumPy skips. Ruff and mypy passed, including
  all tagged workflow gates. Website suite: 13 passed; Worker build/syntax passed.
- The downloaded package identifies version `0.1.1` and the exact tagged source;
  its application executable's Windows File Version is `0.1.1.0`.
- The fresh frozen panel passed its preview smoke check. Both PTT WAV cues have
  the expected format/duration. Required model-license texts and runtime notices
  are present: 43 main, 70 STT and 122 TTS distribution records. Model weights
  are absent from the application archive.
- Exact release STT worker inference passed using a synthetic tone (`no_speech`).
  Fresh frozen English/Turkish default-voice synthesis passed for replies and
  automatic announcements through one reused TTS worker. No microphone capture or
  audio playback was used for these checks.
- Updater checks against the public release passed: `0.1.0` detects `0.1.1`, and
  `0.1.1` reports no update. Automated tests cover cancellation, corruption,
  idle-only prompts and single-instance/installer handoff.
- Actual installed-version upgrade, clean-machine uninstall, listening quality and
  racing latency are not independently established by these checks. Package CPU
  inference, unsigned installers and imperfect LFM replies remain documented limits.

## Upgrade and follow-up

The public 0.1.0 app predates the updater. Install v0.1.1 over it manually once;
in-place upgrade preserves models, profiles and settings. Explicit uninstall now
removes the standard model and update-installer caches.

The installer Product Version is `0.1.1`. Its separate numeric File Version remains
Inno Setup's default `0.0.0.0` (a cosmetic packaging follow-up); application identity,
installer product version, Add/Remove Programs version and updater comparisons use
`0.1.1`. Set an explicit `VersionInfoVersion` in a future build if Explorer's installer
File Version must match; see [the Inno Setup directive](https://jrsoftware.org/ishelp/topic_setup_versioninfoversion.htm).
