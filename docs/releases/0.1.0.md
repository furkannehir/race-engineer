## Completing the release

1. Review and commit the prepared changes and completed clearance evidence.
2. Run the source checks and the Windows package workflow on that final commit.
3. Complete clean-machine acceptance against those exact artifacts.
4. Review `distribution/RELEASE_NOTES.md`, then create and push `v0.1.0` on the
   verified commit, following `docs/distribution.md`.
5. Review the workflow's draft release, replace generated notes with the prepared
   release notes, verify asset checksums, then publish the draft.

The download dashboard reads GitHub's public `v0.1.0` release. It enables downloads
only when all three expected assets are uploaded. Drafts and Actions test artifacts
do not enable download buttons.
