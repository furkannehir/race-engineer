# Pitward 0.1.0 distribution review

Recorded on 2026-11-09 for component set 3 and the Windows x64 release.

## Maintainer acceptance and original audio

The maintainer confirmed that the radio beep is an original asset created for
this project, rather than an uncleared external recording. The procedural squelch
is generated by `scripts/build_radio_cues.py`. The beep and derived mixes are
distributed under the project's GPL-3.0 license.

After receiving `dist/candidate-0.1.0/Pitward-Setup-0.1.0-windows-x64.exe`, the
maintainer reported that installation and use worked perfectly and explicitly
requested publication. That accepted candidate came from source commit
`6b9fabfdcbb9a7c29412bc9d9e385597b315d550` and successful workflow run
`42512964682`. No separate claim is made about unreported hardware benchmarks or
individual checklist items. CPU latency and unvalidated Turkish conversation
remain disclosed limitations of the first release.

The final tagged build adds distribution notices, license retention, release
documentation, and the download website source. It does not change the engineer,
models, speech pipeline, or desktop controls accepted by the maintainer. The
tagged workflow must pass its own source and frozen-executable startup checks.

## Bundled application and speech libraries

Pitward remains GPL-3.0 with its corresponding source, configuration, build
scripts, and versioned dependencies available at the public release tag.
PySide/Qt and pygame remain replaceable shared libraries in the folder bundle.
GPL and LGPL texts, Qt source locations, and Material Design font attribution
are retained. Only the icon font actually used by the panel is packaged.

The build collects each environment's installed distribution metadata and
license/NOTICE/COPYING/AUTHORS files into separate runtime license folders with
SHA-256 manifests. These inventories may include installed build dependencies
that are not frozen into the executables. Existing upstream license files inside
speech-worker bundles are retained as well. PyInstaller's bootloader exception
is preserved in its installed distribution's COPYING text.

The public release notes retain the unsigned-build, setup-download, CPU-runtime,
and language limitations. This release is a free download of the open-source
application; no commercial compiler entitlement is asserted by this record.
